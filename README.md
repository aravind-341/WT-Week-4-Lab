# Week 4 Lab

## Web Technologies Lab

This repository contains the HTML program completed during **Week 4** of the lab.

## Experiment

### Designing Frames with Hyperlinks in HTML

The webpage is designed using a **menu frame and a content frame**. Selecting a hyperlink from the menu opens the corresponding webpage in the content frame.

## Files

* `index.html` - Main frameset containing the menu and content frames
* `menu.html` - Navigation menu
* `home.html` - Home page
* `profile.html` - Student profile
* `courses.html` - Courses page
* `contact.html` - Contact details

## Concepts Used

* `<frameset>`
* `<frame>`
* `<a>` Anchor tag
* `src`
* `name`
* `target`
* Hyperlinks
